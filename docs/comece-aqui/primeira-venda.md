# Como anotar minha primeira venda

Depois de criar sua conta no **Fiado Zap**, você já pode começar a registrar suas vendas fiadas.

Anotar uma venda é importante para você saber quem comprou, quanto ficou devendo, quando precisa pagar e quanto ainda falta receber.

Com isso, você evita esquecimentos e mantém o controle do seu fiado direto no celular.

## Antes de anotar uma venda

Antes de registrar uma venda, é recomendado ter um cliente cadastrado.

Se você ainda não cadastrou nenhum cliente, veja primeiro:

[Como cadastrar um cliente](/docs/clientes/cadastrar-cliente)

Depois que o cliente estiver cadastrado, você poderá selecionar esse cliente na hora de criar a venda.

## Passo a passo para anotar uma venda

Siga o passo a passo:

1. Abra o aplicativo **Fiado Zap**.
2. Acesse a opção de **Vendas** ou toque para criar uma nova venda.
3. Selecione o cliente que comprou fiado.
4. Informe o valor da venda.
5. Preencha a descrição da venda, se desejar.
6. Escolha a forma de pagamento ou vencimento, se essa opção aparecer.
7. Confira se os dados estão corretos.
8. Toque em **Salvar**.

Pronto! Sua venda ficará registrada no Fiado Zap.

## O que informar na venda?

Na hora de cadastrar uma venda, preencha as informações com atenção.

### Cliente

Selecione o cliente que fez a compra.

É importante escolher o cliente correto para que a dívida fique salva no histórico da pessoa certa.

### Valor da venda

Informe o valor total da venda.

Exemplo: se o cliente comprou R$ 50,00, informe esse valor no campo da venda.

### Descrição

A descrição serve para você lembrar o que foi vendido.

Você pode escrever algo simples, como:

- Compra de roupas
- Produtos de beleza
- Itens do mercado
- Corte de cabelo
- Serviço realizado
- Venda do dia

Esse campo ajuda bastante quando você precisar consultar o histórico depois.

### Data de vencimento

A data de vencimento indica quando o cliente deverá pagar.

Se a venda for para pagar depois, escolha a data combinada com o cliente.

Se for uma venda à vista, a data pode ser o dia atual.

## Como saber se a venda ficou pendente?

Depois que a venda é salva, ela fica vinculada ao cliente.

Se o cliente ainda não pagou tudo, o valor aparece como pendente.

Na lista de clientes, você poderá ver o cliente com status **Pendente** e o valor em aberto.

Quando o cliente pagar, você poderá registrar o pagamento para atualizar a situação.

## E se o cliente pagar uma parte?

Se o cliente pagar apenas uma parte do valor, você pode registrar um pagamento parcial, caso essa opção esteja disponível na venda.

Exemplo:

O cliente comprou R$ 100,00, mas pagou R$ 40,00.

Nesse caso, ainda ficará um valor restante de R$ 60,00 para receber.

Isso ajuda você a acompanhar exatamente quanto o cliente já pagou e quanto ainda falta.

## Posso parcelar uma venda?

Sim.

Se a venda for parcelada, use a opção de parcelamento no cadastro da venda.

Assim, você consegue organizar melhor as datas e valores que o cliente deverá pagar.

Veja também:

[Como parcelar uma venda](/docs/vendas/parcelar-venda)

## Onde vejo a venda depois?

Depois de salvar, você pode acompanhar a venda em locais como:

- Lista de vendas.
- Detalhes do cliente.
- Histórico do cliente.
- Valores pendentes.

Assim, sempre que precisar consultar uma venda antiga, basta acessar o cliente ou a área de vendas.

## Dicas importantes

Sempre anote a venda no momento em que ela acontecer.

Isso evita esquecer valores, datas ou o nome do cliente.

Também é importante preencher uma descrição simples, para você lembrar depois o que foi vendido.

## Exemplo prático

Imagine que a cliente Maria comprou R$ 80,00 em produtos e combinou de pagar na próxima semana.

No Fiado Zap, você pode:

1. Selecionar a cliente Maria.
2. Informar o valor de R$ 80,00.
3. Colocar uma descrição, como “Produtos de beleza”.
4. Definir a data combinada para pagamento.
5. Salvar a venda.

Depois disso, essa venda ficará registrada e você poderá acompanhar se ela já foi paga ou se ainda está pendente.

## Resumo

Para anotar sua primeira venda no Fiado Zap:

- Cadastre ou selecione um cliente.
- Informe o valor da venda.
- Adicione uma descrição.
- Escolha a data de vencimento, se necessário.
- Salve a venda.

Com a venda registrada, o Fiado Zap ajuda você a controlar quem está devendo e quanto ainda falta receber.
