# Como editar um cliente

Você pode editar um cliente quando precisar corrigir ou atualizar alguma informação.

Por exemplo:

- Nome.
- Telefone.
- Observação.
- Dados de contato.
- Alguma informação cadastrada errada.

## Passo a passo

1. Abra o aplicativo **Fiado Zap**.
2. Toque em **Clientes**.
3. Encontre o cliente que deseja editar.
4. Toque sobre o nome do cliente.
5. Na tela de detalhes do cliente, procure a opção de edição.
6. Altere as informações necessárias.
7. Toque em **Salvar**.

Pronto! Os dados do cliente serão atualizados.

## Como encontrar um cliente mais rápido?

Na tela de clientes, toque no ícone de **lupa**.

Depois, digite o nome do cliente que você deseja encontrar.

A busca ajuda principalmente quando você já tem muitos clientes cadastrados.

## Importante

Alterar os dados do cliente não apaga o histórico de vendas e pagamentos dele.

O histórico continua vinculado ao mesmo cliente.
